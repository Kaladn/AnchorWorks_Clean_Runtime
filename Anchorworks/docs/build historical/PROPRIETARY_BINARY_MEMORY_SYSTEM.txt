SECTION 1: FILE STRUCTURE
================================================================================

FILES ON DISK:
--------------
forge_memory/
├── records.bin          # Append-only record log (main data)
├── wal.bin             # Write-ahead log (crash recovery)
├── string_dict.bin     # String dictionary (compression)
├── index_task.bin      # B+tree: task_id → record_offsets
├── index_engine.bin    # B+tree: (engine, transform, shapes) → offsets
├── index_success.bin   # Bitmap: success=True offsets

└── vcache.bin          # Hot index cache (V-Cache resident)

MEMORY MAP LAYOUT:
------------------
All files are memory-mapped (mmap) for zero-copy access
OS handles paging, we control structure

OFFSET  SIZE    FIELD                   TYPE        ENCODING
------  ----    -----                   ----        --------

4       2       VERSION                 uint16      0x0001

8       8       PULSE_ID                uint64      Monotonic pulse counter
16      1       WORKER_ID               uint8       0-255
17      4       SEQ                     uint32      Sequence within worker
21      8       TIMESTAMP               double      Unix time + milliseconds
29      1       SUCCESS                 uint8       0=False, 1=True
30      2       TASK_ID_REF             uint16      → string_dict offset
32      2       ENGINE_ID_REF           uint16      → string_dict offset
34      2       TRANSFORM_ID_REF        uint16      → string_dict offset
36      2       FAILURE_REASON_REF      uint16      → string_dict offset (0=None)
38      1       GRID_SHAPE_IN_H         uint8       Input grid height
39      1       GRID_SHAPE_IN_W         uint8       Input grid width
40      1       GRID_SHAPE_OUT_H        uint8       Output grid height
41      1       GRID_SHAPE_OUT_W        uint8       Output grid width
42      1       COLOR_COUNT             uint8       Number of unique colors
43      1       TRAIN_PAIR_COUNT        uint8       Number of training pairs tested
44      N       TRAIN_PAIR_INDICES      uint8[]     [0, 1, 2, ...] (N = TRAIN_PAIR_COUNT)
44+N    2       ERROR_METRICS_LEN       uint16      Length of error_metrics blob
46+N    M       ERROR_METRICS_BLOB      bytes       MessagePack encoded dict
46+N+M  2       PARAMS_LEN              uint16      Length of params blob
48+N+M  P       PARAMS_BLOB             bytes       MessagePack encoded dict
48+N+M+P 2      CONTEXT_LEN             uint16      Length of context blob
50+N+M+P C      CONTEXT_BLOB            bytes       MessagePack encoded dict
50+N+M+P+C 4    CHECKSUM                uint32      CRC32 of entire record

TOTAL: Variable (avg 500 bytes)

NOTES:
- All multi-byte integers are LITTLE ENDIAN
- String fields use dictionary compression (offset into string_dict.bin)
- Variable-length dicts use MessagePack (compact binary JSON)
- Checksum ensures data integrity

ENTRY FORMAT:
-------------
OFFSET  SIZE    FIELD
------  ----    -----
0       2       STRING_LENGTH           uint16
2       N       STRING_DATA             UTF-8 bytes
2+N     4       HASH                    uint32 (for fast lookup)

LOOKUP TABLE (in memory):
-------------------------
hash_map<string_hash, offset_in_file>

WRITE ALGORITHM:
----------------
FUNCTION add_string(s: string) -> uint16:
    hash = crc32(s)
    IF hash IN lookup_table:
        RETURN lookup_table[hash]
    ELSE:
        offset = append_to_file(string_dict.bin, s)
        lookup_table[hash] = offset
        RETURN offset

READ ALGORITHM:
---------------
FUNCTION get_string(offset: uint16) -> string:
    mmap_ptr = mmap_base + offset
    length = read_uint16(mmap_ptr)
    data = read_bytes(mmap_ptr + 2, length)
    RETURN utf8_decode(data)

SECTION 4: B+TREE INDEX STRUCTURE
================================================================================

PURPOSE: Fast lookups by task_id, (engine, transform, shapes), timestamp

FILE FORMAT (per index):
------------------------
HEADER:
-------
OFFSET  SIZE    FIELD
------  ----    -----
0       4       MAGIC                   0x42545245 ("BTRE")
4       2       VERSION                 uint16
6       2       NODE_SIZE               uint16 (e.g., 4096 = page size)
8       4       ROOT_OFFSET             uint32
12      4       NODE_COUNT              uint32
16      4       ENTRY_COUNT             uint32
20      ...     NODES (fixed-size blocks)

NODE STRUCTURE (Internal):
--------------------------
OFFSET  SIZE    FIELD
------  ----    -----
0       1       NODE_TYPE               uint8 (0=Internal, 1=Leaf)
1       2       KEY_COUNT               uint16
3       ...     KEYS (variable, depends on key type)
...     ...     CHILD_OFFSETS           uint32[] (KEY_COUNT + 1 pointers)

NODE STRUCTURE (Leaf):
----------------------
OFFSET  SIZE    FIELD
------  ----    -----
0       1       NODE_TYPE               uint8 (1=Leaf)
1       2       KEY_COUNT               uint16
3       ...     KEYS (variable)
...     ...     VALUE_LISTS             offset_list[] (each key → list of record offsets)
...     4       NEXT_LEAF               uint32 (for range scans)

KEY FORMATS:
------------
1. task_id index:
   KEY = uint16 (string_dict offset)
   
2. (engine, transform, shapes) composite index:
   KEY = struct {
       engine_ref: uint16,
       transform_ref: uint16,
       shape_in_h: uint8,
       shape_in_w: uint8,
       shape_out_h: uint8,
       shape_out_w: uint8
   } // 10 bytes total
   
3. timestamp index:
   KEY = double (8 bytes)

VALUE FORMAT:
-------------
VALUE = offset_list {
    count: uint16,
    offsets: uint64[] // offsets into records.bin
}

SEARCH ALGORITHM:
-----------------
FUNCTION search(key) -> offset_list:
    node_offset = root_offset
    WHILE TRUE:
        node = mmap_read(node_offset)
        IF node.type == LEAF:
            idx = binary_search(node.keys, key)
            IF idx FOUND:
                RETURN node.value_lists[idx]
            ELSE:
                RETURN empty_list
        ELSE: // Internal node
            idx = binary_search(node.keys, key) // find child
            node_offset = node.child_offsets[idx]

INSERT ALGORITHM:
-----------------
FUNCTION insert(key, record_offset):
    leaf = find_leaf(key)
    IF key EXISTS in leaf:
        append_to_value_list(leaf, key, record_offset)
    ELSE:
        insert_new_key(leaf, key, [record_offset])
    
    IF leaf.key_count > MAX_KEYS:
        split_leaf(leaf)
        propagate_split_upward()

RANGE SCAN:
-----------
FUNCTION range_scan(start_key, end_key) -> offset_list:
    results = []
    leaf = find_leaf(start_key)
    WHILE leaf != NULL AND leaf.min_key <= end_key:
        FOR key IN leaf.keys WHERE start_key <= key <= end_key:
            results.append(leaf.value_lists[key])
        leaf = leaf.next_leaf // follow linked list
    RETURN results

BITMAP ENCODING:
----------------
- Each record has a unique ID (sequential, 0-based)
- Bit position = record_id
- Bit value: 1 = in set, 0 = not in set

OPERATIONS:
-----------
FUNCTION set_success(record_id, success):
    IF success:
        bitmap_true[record_id] = 1
    ELSE:
        bitmap_false[record_id] = 1

FUNCTION get_successes() -> record_id_list:
    RETURN all_set_bits(bitmap_true)

FUNCTION intersect(offset_list, success_filter) -> offset_list:
    IF success_filter == TRUE:
        RETURN [off FOR off IN offset_list IF bitmap_true[offset_to_id(off)] == 1]
    ELSE:
        RETURN [off FOR off IN offset_list IF bitmap_false[offset_to_id(off)] == 1]

OFFSET  SIZE    FIELD
------  ----    -----
0       4       MAGIC                   0x57414C00 ("WAL\0")
4       8       CHECKPOINT_PULSE_ID     uint64 (last committed pulse)
12      ...     LOG_ENTRIES (append-only)

LOG ENTRY FORMAT:
-----------------
OFFSET  SIZE    FIELD
------  ----    -----
0       1       ENTRY_TYPE              uint8 (1=Record, 2=Checkpoint)
1       8       PULSE_ID                uint64
9       N       PAYLOAD                 bytes (full record if type=1)
9+N     4       CHECKSUM                uint32

WRITE PROTOCOL:
---------------
FUNCTION write_batch(records):
    // Step 1: Write to WAL
    FOR record IN records:
        wal_entry = {type: 1, pulse_id: record.pulse_id, payload: record}
        append_to_wal(wal_entry)
    fsync(wal.bin) // Force to disk
    
    // Step 2: Write to main log
    FOR record IN records:
        offset = append_to_file(records.bin, record)
        update_all_indexes(record, offset)
    
    // Step 3: Checkpoint
    checkpoint_entry = {type: 2, pulse_id: current_pulse_id}
    append_to_wal(checkpoint_entry)
    fsync(wal.bin)
    
    // Step 4: Truncate WAL (optional, periodic)
    IF wal_size > THRESHOLD:
        truncate_wal_to_checkpoint()

RECOVERY PROTOCOL:
------------------
FUNCTION recover_from_crash():
    last_checkpoint = read_last_checkpoint(wal.bin)
    records_to_replay = read_wal_since(last_checkpoint)
    
    FOR record IN records_to_replay:
        offset = append_to_file(records.bin, record)
        update_all_indexes(record, offset)
    
    truncate_wal()
    RETURN "Recovery complete"

PURPOSE: Keep most-accessed index entries in L3 cache (96MB)

SIZE: 64 MB (fits in V-Cache with room for OS)

STRUCTURE:
----------
OFFSET  SIZE    FIELD
------  ----    -----
0       4       MAGIC                   0x56434148 ("VCAH")
4       4       ENTRY_COUNT             uint32
8       4       HIT_COUNT               uint32
12      4       MISS_COUNT              uint32
16      ...     CACHE_ENTRIES (hash table)

CACHE ENTRY:
------------
OFFSET  SIZE    FIELD
------  ----    -----
0       8       KEY_HASH                uint64
8       2       VALUE_COUNT             uint16
10      N       VALUE_OFFSETS           uint64[] (up to 100 offsets)

CACHE STRATEGY: LRU (Least Recently Used)
------------------------------------------
FUNCTION lookup(key):
    hash = hash_key(key)
    entry = vcache_hash_table[hash]
    
    IF entry EXISTS:
        hit_count++
        touch_lru(entry) // Mark as recently used
        RETURN entry.value_offsets
    ELSE:
        miss_count++
        result = search_disk_index(key)
        insert_into_cache(hash, result)
        RETURN result

EVICTION:
---------
FUNCTION insert_into_cache(hash, offsets):
    IF cache_full():
        evict_lru_entry()
    
    entry = {key_hash: hash, value_offsets: offsets}
    vcache_hash_table[hash] = entry
    add_to_lru_list(entry)

PINNING TO V-CACHE:
-------------------
FUNCTION pin_to_vcache():
    // Use madvise to hint OS to keep in cache
    madvise(vcache.bin, MADV_WILLNEED | MADV_RANDOM)
    
    // Pin writer thread to V-Cache cores
    set_cpu_affinity(writer_thread, cores=[0, 1])

================================================================================
SECTION 8: PULSE WRITER (MULTI-THREADED)
================================================================================

ARCHITECTURE:
-------------
8 Worker Threads → 8 Queues → 1 Pulse Writer → Disk

QUEUE STRUCTURE (per worker):
------------------------------
struct WorkerQueue {
    buffer: CircularBuffer<Record>[1000],  // Fixed-size ring buffer
    head: atomic<uint32>,
    tail: atomic<uint32>,
    worker_id: uint8
}

CIRCULAR BUFFER (lock-free):
----------------------------
FUNCTION enqueue(queue, record):
    LOOP:
        tail = atomic_load(queue.tail)
        next_tail = (tail + 1) % BUFFER_SIZE
        
        IF next_tail == atomic_load(queue.head):
            // Queue full, block worker
            sleep_microseconds(100)
            CONTINUE
        
        queue.buffer[tail] = record
        IF atomic_compare_exchange(queue.tail, tail, next_tail):
            RETURN success
        // CAS failed, retry

FUNCTION dequeue(queue) -> Record:
    LOOP:
        head = atomic_load(queue.head)
        
        IF head == atomic_load(queue.tail):
            RETURN NULL // Queue empty
        
        record = queue.buffer[head]
        next_head = (head + 1) % BUFFER_SIZE
        
        IF atomic_compare_exchange(queue.head, head, next_head):
            RETURN record
        // CAS failed, retry

PULSE WRITER MAIN LOOP:
-----------------------
FUNCTION pulse_writer_loop():
    pulse_id = 0
    
    WHILE running:
        pulse_start_time = monotonic_clock()
        batch = []
        
        // Round-robin drain from all workers
        FOR worker_id IN 0..7:
            queue = worker_queues[worker_id]
            drain_count = 0
            
            WHILE drain_count < MAX_PER_WORKER_PER_PULSE:
                record = dequeue(queue)
                IF record == NULL:
                    BREAK
                
                record.pulse_id = pulse_id
                record.worker_id = worker_id
                record.seq = drain_count
                batch.append(record)
                drain_count++
        
        // Write batch to disk
        IF batch NOT empty:
            write_batch_to_disk(batch)
            pulse_id++
        
        // Sleep until next pulse
        elapsed = monotonic_clock() - pulse_start_time
        IF elapsed < PULSE_INTERVAL:
            sleep(PULSE_INTERVAL - elapsed)

BATCH WRITE:
------------
FUNCTION write_batch_to_disk(batch):
    // Step 1: Write to WAL
    write_to_wal(batch)
    
    // Step 2: Compress strings
    FOR record IN batch:
        record.task_id_ref = add_string(record.task_id)
        record.engine_id_ref = add_string(record.engine_id)
        record.transform_id_ref = add_string(record.transform_id)
        record.failure_reason_ref = add_string(record.failure_reason)
    
    // Step 3: Serialize and append to records.bin
    offsets = []
    FOR record IN batch:
        binary_data = serialize_record(record)
        offset = append_bytes(records.bin, binary_data)
        offsets.append(offset)
    
    // Step 4: Update all indexes
    FOR i IN 0..batch.length:
        record = batch[i]
        offset = offsets[i]
        
        update_index_task(record.task_id_ref, offset)
        update_index_engine(record, offset)
        update_index_success(offset, record.success)
        update_index_time(record.timestamp, offset)
    
    // Step 5: Checkpoint WAL
    checkpoint_wal(pulse_id)
    
    // Step 6: Update metadata
    metadata.pulse_id = pulse_id
    metadata.record_count += batch.length
    flush_metadata()

FUNCTION get_templates(engine_id, transform_id, shape_in, shape_out):

READ RECORD:
------------
FUNCTION read_record_at_offset(offset) -> Record:
    mmap_ptr = mmap_base(records.bin) + offset
    
    // Read header
    magic = read_uint32(mmap_ptr + 0)
    IF magic != 0x464F5247:
        RETURN error("Corrupted record")
    
    version = read_uint16(mmap_ptr + 4)
    length = read_uint16(mmap_ptr + 6)
    
    // Read fixed fields
    record = {
        pulse_id: read_uint64(mmap_ptr + 8),
        worker_id: read_uint8(mmap_ptr + 16),
        seq: read_uint32(mmap_ptr + 17),
        timestamp: read_double(mmap_ptr + 21),
        success: read_uint8(mmap_ptr + 29) == 1,
        task_id: get_string(read_uint16(mmap_ptr + 30)),
        engine_id: get_string(read_uint16(mmap_ptr + 32)),
        transform_id: get_string(read_uint16(mmap_ptr + 34)),
        failure_reason: get_string(read_uint16(mmap_ptr + 36)),
        grid_shape_in: [read_uint8(mmap_ptr + 38), read_uint8(mmap_ptr + 39)],
        grid_shape_out: [read_uint8(mmap_ptr + 40), read_uint8(mmap_ptr + 41)],
        color_count: read_uint8(mmap_ptr + 42),
        train_pair_count: read_uint8(mmap_ptr + 43)
    }
    
    // Read variable fields
    offset_var = 44
    record.train_pair_indices = read_bytes(mmap_ptr + offset_var, record.train_pair_count)
    offset_var += record.train_pair_count
    
    error_len = read_uint16(mmap_ptr + offset_var)
    offset_var += 2
    record.error_metrics = msgpack_decode(read_bytes(mmap_ptr + offset_var, error_len))
    offset_var += error_len
    
    params_len = read_uint16(mmap_ptr + offset_var)
    offset_var += 2
    record.params = msgpack_decode(read_bytes(mmap_ptr + offset_var, params_len))
    offset_var += params_len
    
    context_len = read_uint16(mmap_ptr + offset_var)
    offset_var += 2
    record.context = msgpack_decode(read_bytes(mmap_ptr + offset_var, context_len))
    offset_var += context_len
    
    // Verify checksum
    checksum_stored = read_uint32(mmap_ptr + offset_var)
    checksum_computed = crc32(mmap_ptr, offset_var)
    IF checksum_stored != checksum_computed:
        RETURN error("Checksum mismatch")
    
    RETURN record

SECTION 10: SYSTEM INITIALIZATION
================================================================================

FUNCTION initialize_system():
    // Create directory
    create_directory("forge_memory/")
    
    // Initialize files
    create_file("records.bin", initial_size=1GB)
    create_file("wal.bin", initial_size=100MB)
    create_file("string_dict.bin", initial_size=10MB)
    create_file("index_task.bin", initial_size=100MB)
    create_file("index_engine.bin", initial_size=100MB)
    create_file("index_success.bin", initial_size=10MB)
    create_file("index_time.bin", initial_size=100MB)
    create_file("metadata.bin", initial_size=4KB)
    create_file("vcache.bin", initial_size=64MB)
    
    // Memory map all files
    mmap_records = mmap("records.bin", MAP_SHARED)
    mmap_wal = mmap("wal.bin", MAP_SHARED)
    mmap_string_dict = mmap("string_dict.bin", MAP_SHARED)
    mmap_index_task = mmap("index_task.bin", MAP_SHARED)
    mmap_index_engine = mmap("index_engine.bin", MAP_SHARED)
    mmap_index_success = mmap("index_success.bin", MAP_SHARED)
    mmap_index_time = mmap("index_time.bin", MAP_SHARED)
    mmap_metadata = mmap("metadata.bin", MAP_SHARED)
    mmap_vcache = mmap("vcache.bin", MAP_SHARED)
    
    // Pin V-Cache to memory
    mlock(mmap_vcache, 64MB)
    madvise(mmap_vcache, MADV_WILLNEED | MADV_RANDOM)
    
    // Initialize metadata
    metadata = {
        magic: 0x4D455441,
        version: 1,
        pulse_id: 0,
        record_count: 0,
        created_timestamp: current_time()
    }
    write_metadata(metadata)
    
    // Initialize worker queues
    FOR i IN 0..7:
        worker_queues[i] = create_circular_buffer(1000)
    
    // Start pulse writer thread
    writer_thread = spawn_thread(pulse_writer_loop)
    set_cpu_affinity(writer_thread, cores=[0])
    
    RETURN "System initialized"

OPTIMIZATION 1: Batch Index Updates
------------------------------------
Instead of updating indexes one-by-one, batch them:

FUNCTION update_all_indexes_batched(records, offsets):
    // Group by index type
    task_updates = []
    engine_updates = []
    success_updates = []
    time_updates = []
    
    FOR i IN 0..records.length:
        task_updates.append({key: records[i].task_id_ref, offset: offsets[i]})
        engine_updates.append({key: make_engine_key(records[i]), offset: offsets[i]})
        success_updates.append({offset: offsets[i], value: records[i].success})
        time_updates.append({key: records[i].timestamp, offset: offsets[i]})
    
    // Batch insert into each index
    btree_batch_insert(index_task, task_updates)
    btree_batch_insert(index_engine, engine_updates)
    bitmap_batch_set(index_success, success_updates)
    btree_batch_insert(index_time, time_updates)

OPTIMIZATION 2: Prefetch for Sequential Reads
----------------------------------------------
FUNCTION prefetch_records(offset_list):
    FOR offset IN offset_list:
        madvise(mmap_records + offset, 512, MADV_WILLNEED)
    
    // Now read them (they're in cache)
    records = []
    FOR offset IN offset_list:
        records.append(read_record_at_offset(offset))
    
    RETURN records

OPTIMIZATION 3: Bloom Filter for Negative Lookups
--------------------------------------------------
Add bloom filter to each B+tree node to skip empty nodes:

FUNCTION search_with_bloom(key):
    node = root
    WHILE node.type != LEAF:
        IF NOT bloom_filter_contains(node.bloom, key):
            RETURN empty_list // Key definitely not in subtree
        node = find_child(node, key)
    
    RETURN search_leaf(node, key)

OPTIMIZATION 4: Delta Encoding for Timestamps
----------------------------------------------
Store timestamps as deltas from previous record:

FUNCTION encode_timestamp_delta(current, previous):
    delta = current - previous
    RETURN varint_encode(delta) // 1-4 bytes instead of 8

OPTIMIZATION 5: Compression for Large Blobs
--------------------------------------------
FUNCTION compress_blob(data):
    IF length(data) > 100:
        compressed = lz4_compress(data)
        IF length(compressed) < length(data) * 0.8:
            RETURN {compressed: true, data: compressed}
    
    RETURN {compressed: false, data: data}

        writes_per_second: metadata.record_count / uptime_seconds,
        batch_size_avg: sum(batch_sizes) / batch_count,
        queue_depth_per_worker: [queue.size() FOR queue IN worker_queues],
        pulse_latency_ms: avg(pulse_latencies),

FUNCTION graceful_shutdown():
    PRINT "Initiating graceful shutdown..."
    
    // Step 1: Stop accepting new writes
    running = false
    
    // Step 2: Drain all worker queues
    PRINT "Draining worker queues..."
    WHILE any_queue_not_empty():
        // Pulse writer continues draining
        sleep(PULSE_INTERVAL)
    
    // Step 3: Final checkpoint
    PRINT "Writing final checkpoint..."
    checkpoint_wal(metadata.pulse_id)
    
    // Step 4: Flush all indexes
    PRINT "Flushing indexes..."
    msync(mmap_index_task)
    msync(mmap_index_engine)
    msync(mmap_index_success)
    msync(mmap_index_time)
    
    // Step 5: Flush metadata
    PRINT "Flushing metadata..."
    metadata.shutdown_timestamp = current_time()
    write_metadata(metadata)
    msync(mmap_metadata)
    
    // Step 6: Unmap all files
    PRINT "Unmapping files..."
    munmap(mmap_records)
    munmap(mmap_wal)
    munmap(mmap_string_dict)
    munmap(mmap_index_task)
    munmap(mmap_index_engine)
    munmap(mmap_index_success)
    munmap(mmap_index_time)
    munmap(mmap_metadata)
    munmap(mmap_vcache)
    
    PRINT "Shutdown complete."
